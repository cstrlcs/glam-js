# glam-js

## API Reference

- `BVec2` - A 2-dimensional `bool` vector mask.
  - `x: boolean`
  - `y: boolean`
  - `FALSE: BVec2` - All false.
  - `TRUE: BVec2` - All true.
  - `new: (x: boolean, y: boolean) => BVec2` - Creates a new vector mask.
  - `splat: (v: boolean) => BVec2` - Creates a vector mask with all elements set to `v`.
  - `fromArray: (a: [boolean, boolean]) => BVec2` - Creates a new vector mask from a bool array.
  - `bitmask: () => number` - Returns a bitmask with the lowest 2 bits set from the elements of `this`. A true element results in a `1` bit and a false element in a `0` bit. Element `x` goes into the first lowest bit, element `y` into the second, etc.
  - `any: () => boolean` - Returns true if any of the elements are true, false otherwise.
  - `all: () => boolean` - Returns true if all the elements are true, false otherwise.
  - `test: (index: 0 | 1) => boolean` - Tests the value at `index`. Throws a `RangeError` if `index` is greater than 1.
  - `set: (index: 0 | 1, value: boolean) => void` - Sets the element at `index`. Throws a `RangeError` if `index` is greater than 1.
  - `bitand: (rhs: BVec2) => BVec2`
  - `bitor: (rhs: BVec2) => BVec2`
  - `bitxor: (rhs: BVec2) => BVec2`
  - `bitandAssign: (rhs: BVec2) => this`
  - `bitorAssign: (rhs: BVec2) => this`
  - `bitxorAssign: (rhs: BVec2) => this`
  - `not: () => BVec2`
  - `eq: (rhs: boolean | BVec2) => boolean`
  - `ne: (rhs: boolean | BVec2) => boolean`
  - `toString: () => string`
  - `bvec2: (x: boolean, y: boolean) => BVec2` - Creates a 2-dimensional `bool` vector mask.

- `BVec3` - A 3-dimensional `bool` vector mask.
  - `x: boolean`
  - `y: boolean`
  - `z: boolean`
  - `FALSE: BVec3` - All false.
  - `TRUE: BVec3` - All true.
  - `new: (x: boolean, y: boolean, z: boolean) => BVec3` - Creates a new vector mask.
  - `splat: (v: boolean) => BVec3` - Creates a vector mask with all elements set to `v`.
  - `fromArray: (a: [boolean, boolean, boolean]) => BVec3` - Creates a new vector mask from a bool array.
  - `bitmask: () => number` - Returns a bitmask with the lowest 3 bits set from the elements of `this`. A true element results in a `1` bit and a false element in a `0` bit. Element `x` goes into the first lowest bit, element `y` into the second, etc.
  - `any: () => boolean` - Returns true if any of the elements are true, false otherwise.
  - `all: () => boolean` - Returns true if all the elements are true, false otherwise.
  - `test: (index: 0 | 1 | 2) => boolean` - Tests the value at `index`. Throws a `RangeError` if `index` is greater than 2.
  - `set: (index: 0 | 1 | 2, value: boolean) => void` - Sets the element at `index`. Throws a `RangeError` if `index` is greater than 2.
  - `bitand: (rhs: BVec3) => BVec3`
  - `bitor: (rhs: BVec3) => BVec3`
  - `bitxor: (rhs: BVec3) => BVec3`
  - `bitandAssign: (rhs: BVec3) => this`
  - `bitorAssign: (rhs: BVec3) => this`
  - `bitxorAssign: (rhs: BVec3) => this`
  - `not: () => BVec3`
  - `eq: (rhs: boolean | BVec3) => boolean`
  - `ne: (rhs: boolean | BVec3) => boolean`
  - `toString: () => string`
  - `bvec3: (x: boolean, y: boolean, z: boolean) => BVec3` - Creates a 3-dimensional `bool` vector mask.

- `BVec4` - A 4-dimensional `bool` vector mask.
  - `x: boolean`

  - `new: (x: boolean, y: boolean, z: boolean, w: boolean) => BVec4` - Creates a new vector mask.
  - `splat: (v: boolean) => BVec4` - Creates a vector mask with all elements set to `v`.
  - `fromArray: (a: [boolean, boolean, boolean, boolean]) => BVec4` - Creates a new vector mask from a bool array.
  - `bitmask: () => number` - Returns a bitmask with the lowest 4 bits set from the elements of `this`. A true element results in a `1` bit and a false element in a `0` bit. Element `x` goes into the first lowest bit, element `y` into the second, etc.
  - `any: () => boolean` - Returns true if any of the elements are true, false otherwise.
  - `all: () => boolean` - Returns true if all the elements are true, false otherwise.
  - `test: (index: 0 | 1 | 2 | 3) => boolean` - Tests the value at `index`. Throws a `RangeError` if `index` is greater than 3.
  - `set: (index: 0 | 1 | 2 | 3, value: boolean) => void` - Sets the element at `index`. Throws a `RangeError` if `index` is greater than 3.
  - `bitand: (rhs: BVec4) => BVec4`
  - `bitor: (rhs: BVec4) => BVec4`
  - `bitxor: (rhs: BVec4) => BVec4`
  - `bitandAssign: (rhs: BVec4) => this`
  - `bitorAssign: (rhs: BVec4) => this`
  - `bitxorAssign: (rhs: BVec4) => this`
  - `not: () => BVec4`
  - `eq: (rhs: boolean | BVec4) => boolean`
  - `ne: (rhs: boolean | BVec4) => boolean`
  - `toString: () => string`
  - `bvec4: (x: boolean, y: boolean, z: boolean, w: boolean) => BVec4` - Creates a 4-dimensional `bool` vector mask.

- `Vec2` - A 2-dimensional vector.
  - `x: number`
  - `y: number`
  - `ZERO: Vec2` - All zeroes.
  - `ONE: Vec2` - All ones.
  - `NEG_ONE: Vec2` - All negative ones.
  - `MIN: Vec2` - All `-Number.MAX_VALUE`.
  - `MAX: Vec2` - All `Number.MAX_VALUE`.
  - `NAN: Vec2` - All `NaN`.
  - `INFINITY: Vec2` - All `Infinity`.
  - `NEG_INFINITY: Vec2` - All `-Infinity`.
  - `X: Vec2` - A unit vector pointing along the positive X axis.
  - `Y: Vec2` - A unit vector pointing along the positive Y axis.
  - `NEG_X: Vec2` - A unit vector pointing along the negative X axis.
  - `NEG_Y: Vec2` - A unit vector pointing along the negative Y axis.
  - `AXES: Vec2[]` - The unit axes.
  - `new: (x: number, y: number) => Vec2` - Creates a new vector.
  - `splat: (v: number) => Vec2` - Creates a vector with all elements set to `v`.
  - `map: (f: (value: number) => number) => Vec2` - Returns a vector containing each element of `this` modified by a mapping function `f`.
  - `select: (mask: BVec2, ifTrue: Vec2, ifFalse: Vec2) => Vec2` - Creates a vector from the elements in `ifTrue` and `ifFalse`, selecting which to use for each element of `this`. A true element in the mask uses the corresponding element from `ifTrue`, and false uses the element from `ifFalse`.
  - `fromArray: (a: [number, number]) => Vec2` - Creates a new vector from an array.
  - `clone: () => Vec2`
  - `toArray: () => [number, number]` - Converts `this` to `[x, y]`
  - `fromSlice: (slice: ArrayLike<number>) => Vec2` - Creates a vector from the first 2 values in `slice`. Throws a `RangeError` if `slice` is less than 2 elements long.
  - `writeToSlice: (slice: { [index: number]: number; readonly length: number; }) => void` - Writes the elements of `this` to the first 2 elements in `slice`. Throws a `RangeError` if `slice` is less than 2 elements long.
  - `extend: (z: number) => Vec3` - Creates a 3D vector from `this` and the given `z` value.
  - `withX: (x: number) => Vec2` - Creates a 2D vector from `this` with the given value of `x`.
  - `withY: (y: number) => Vec2` - Creates a 2D vector from `this` with the given value of `y`.
  - `dot: (rhs: Vec2) => number` - Computes the dot product of `this` and `rhs`.
  - `dotIntoVec: (rhs: Vec2) => Vec2` - Returns a vector where every component is the dot product of `this` and `rhs`.
  - `min: (rhs: Vec2) => Vec2` - Returns a vector containing the minimum values for each element of `this` and `rhs`. In other words this computes `[min(x, rhs.x), min(this.y, rhs.y), ..]`.
  - `max: (rhs: Vec2) => Vec2` - Returns a vector containing the maximum values for each element of `this` and `rhs`. In other words this computes `[max(this.x, rhs.x), max(this.y, rhs.y), ..]`.
  - `clamp: (min: Vec2, max: Vec2) => Vec2` - Component-wise clamping of values, similar to `Math.min(Math.max(value, min), max)`. Each element in `min` must be less-or-equal to the corresponding element in `max`.
  - `minElement: () => number` - Returns the horizontal minimum of `this`. In other words this computes `min(x, y, ..)`.
  - `maxElement: () => number` - Returns the horizontal maximum of `this`. In other words this computes `max(x, y, ..)`.
  - `minPosition: () => number` - Returns the index of the first minimum element of `this`.
  - `maxPosition: () => number` - Returns the index of the first maximum element of `this`.
  - `elementSum: () => number` - Returns the sum of all elements of `this`. In other words, this computes `this.x + this.y + ..`.
  - `elementProduct: () => number` - Returns the product of all elements of `this`. In other words, this computes `this.x * this.y * ..`.
  - `cmpeq: (rhs: Vec2) => BVec2` - Returns a vector mask containing the result of a `==` comparison for each element of `this` and `rhs`. In other words, this computes `[this.x == rhs.x, this.y == rhs.y, ..]` for all elements.
  - `cmpne: (rhs: Vec2) => BVec2` - Returns a vector mask containing the result of a `!=` comparison for each element of `this` and `rhs`. In other words this computes `[this.x != rhs.x, this.y != rhs.y, ..]` for all elements.
  - `cmpge: (rhs: Vec2) => BVec2` - Returns a vector mask containing the result of a `>=` comparison for each element of `this` and `rhs`. In other words this computes `[this.x >= rhs.x, this.y >= rhs.y, ..]` for all elements.
  - `cmpgt: (rhs: Vec2) => BVec2` - Returns a vector mask containing the result of a `>` comparison for each element of `this` and `rhs`. In other words this computes `[this.x > rhs.x, this.y > rhs.y, ..]` for all elements.
  - `cmple: (rhs: Vec2) => BVec2` - Returns a vector mask containing the result of a `<=` comparison for each element of `this` and `rhs`. In other words this computes `[this.x <= rhs.x, this.y <= rhs.y, ..]` for all elements.
  - `cmplt: (rhs: Vec2) => BVec2` - Returns a vector mask containing the result of a `<` comparison for each element of `this` and `rhs`. In other words this computes `[this.x < rhs.x, this.y < rhs.y, ..]` for all elements.
  - `abs: () => Vec2` - Returns a vector containing the absolute value of each element of `this`.
  - `signum: () => Vec2` - Returns a vector with elements representing the sign of `this`. - `1.0` if the number is positive, `+0.0` or `Infinity` - `-1.0` if the number is negative, `-0.0` or `-Infinity` - `NaN` if the number is `NaN`
  - `copysign: (rhs: Vec2) => Vec2` - Returns a vector with signs of `rhs` and the magnitudes of `this`.
  - `isNegativeBitmask: () => number` - Returns a bitmask with the lowest 2 bits set to the sign bits from the elements of `this`. A negative element results in a `1` bit and a positive element in a `0` bit. Element `x` goes into the first lowest bit, element `y` into the second, etc. An element is negative if it has a negative sign, including -0.0 and negative infinity.
  - `isNegativeMask: () => BVec2` - Returns a mask indicating which components are negative. An element is negative if it has a negative sign, including -0.0 and negative infinity.
  - `isFinite: () => boolean` - Returns `true` if, and only if, all elements are finite. If any element is either `NaN`, positive or negative infinity, this will return `false`.
  - `isFiniteMask: () => BVec2` - Performs `Number.isFinite` on each element of this, returning a vector mask of the results. In other words, this computes `[Number.isFinite(x), Number.isFinite(y), ...]`.
  - `isNan: () => boolean` - Returns `true` if any elements are `NaN`.
  - `isNanMask: () => BVec2` - Performs `Number.isNaN` on each element of this, returning a vector mask of the results. In other words, this computes `[Number.isNaN(x), Number.isNaN(y), ...]`.
  - `length: () => number` - Computes the length of `this`.
  - `lengthSquared: () => number` - Computes the squared length of `this`. This is faster than `length()` as it avoids a square root operation.
  - `lengthRecip: () => number` - Computes `1.0 / length()`. For valid results, `this` must _not_ be of length zero.
  - `distance: (rhs: Vec2) => number` - Computes the Euclidean distance between two points in space.
  - `distanceSquared: (rhs: Vec2) => number` - Compute the squared euclidean distance between two points in space.
  - `divEuclid: (rhs: Vec2) => Vec2` - Returns the element-wise quotient of Euclidean division of `this` by `rhs`.
  - `remEuclid: (rhs: Vec2) => Vec2` - Returns the element-wise remainder of Euclidean division of `this` by `rhs`.
  - `normalize: () => Vec2` - Returns `this` normalized to length 1.0. For valid results, `this` must be finite and _not_ of length zero, nor very close to zero. See also `tryNormalize()` and `normalizeOrZero()`.
  - `tryNormalize: () => Vec2` - Returns `this` normalized to length 1.0 if possible, else returns `undefined`. In particular, if the input is zero (or very close to zero), or non-finite, the result of this operation will be `undefined`. See also `normalizeOrZero()`.
  - `normalizeOr: (fallback: Vec2) => Vec2` - Returns `this` normalized to length 1.0 if possible, else returns a fallback value. In particular, if the input is zero (or very close to zero), or non-finite, the result of this operation will be the fallback value. See also `tryNormalize()`.
  - `normalizeOrZero: () => Vec2` - Returns `this` normalized to length 1.0 if possible, else returns zero. In particular, if the input is zero (or very close to zero), or non-finite, the result of this operation will be zero. See also `tryNormalize()`.
  - `normalizeAndLength: () => [Vec2, number]` - Returns `this` normalized to length 1.0 and the length of `this`. If `this` is zero length then `[Vec2.X, 0.0]` is returned.
  - `isNormalized: () => boolean` - Returns whether `this` is length `1.0` or not. Uses a precision threshold of approximately `1e-4`.
  - `projectOnto: (rhs: Vec2) => Vec2` - Returns the vector projection of `this` onto `rhs`. `rhs` must be of non-zero length.
  - `rejectFrom: (rhs: Vec2) => Vec2` - Returns the vector rejection of `this` from `rhs`. The vector rejection is the vector perpendicular to the projection of `this` onto `rhs`, in rhs words the result of `this.sub(this.projectOnto(rhs))`. `rhs` must be of non-zero length.
  - `projectOntoNormalized: (rhs: Vec2) => Vec2` - Returns the vector projection of `this` onto `rhs`. `rhs` must be normalized.
  - `rejectFromNormalized: (rhs: Vec2) => Vec2` - Returns the vector rejection of `this` from `rhs`. The vector rejection is the vector perpendicular to the projection of `this` onto `rhs`, in rhs words the result of `this.sub(this.projectOnto(rhs))`. `rhs` must be normalized.
  - `round: () => Vec2` - Returns a vector containing the nearest integer to a number for each element of `this`. Round half-way cases away from 0.0.
  - `floor: () => Vec2` - Returns a vector containing the largest integer less than or equal to a number for each element of `this`.
  - `ceil: () => Vec2` - Returns a vector containing the smallest integer greater than or equal to a number for each element of `this`.
  - `trunc: () => Vec2` - Returns a vector containing the integer part each element of `this`. This means numbers are always truncated towards zero.
  - `step: (rhs: Vec2) => Vec2` - Returns a vector containing `0.0` if `rhs < this` and 1.0 otherwise. Similar to glsl's step(edge, x), which translates into edge.step(x)
  - `smoothstep: (edge0: Vec2, edge1: Vec2) => Vec2` - Performs Hermite interpolation between `0.0` and `1.0` using `x` normalized to `[edge0, edge1]`. This is equivalent to `t * t * (3.0 - 2.0 * t)`, where `t` is clamped to `[0.0, 1.0]`. Results are undefined if any element of `edge0` is greater than or equal to the corresponding element of `edge1`.
  - `saturate: () => Vec2` - Returns a vector containing all elements of `this` clamped to the range of `[0, 1]`.
  - `fract: () => Vec2` - Returns a vector containing the fractional part of the vector as `this.sub(this.trunc())`. Note that this differs from the GLSL implementation of `fract` which returns `this.sub(this.floor())`. Note that this is fast but not precise for large numbers.
  - `fractGl: () => Vec2` - Returns a vector containing the fractional part of the vector as `this.sub(this.floor())`. Note that this differs from the Rust implementation of `fract` which returns `this.sub(this.trunc())`. Note that this is fast but not precise for large numbers.
  - `exp: () => Vec2` - Returns a vector containing `e^this` (the exponential function) for each element of `this`.
  - `exp2: () => Vec2` - Returns a vector containing `2^this` for each element of `this`.
  - `ln: () => Vec2` - Returns a vector containing the natural logarithm for each element of `this`. This returns NaN when the element is negative and negative infinity when the element is zero.
  - `log2: () => Vec2` - Returns a vector containing the base 2 logarithm for each element of `this`. This returns NaN when the element is negative and negative infinity when the element is zero.
  - `powf: (n: number) => Vec2` - Returns a vector containing each element of `this` raised to the power of `n`.
  - `sqrt: () => Vec2` - Returns a vector containing the square root for each element of `this`. This returns NaN when the element is negative.
  - `cos: () => Vec2` - Returns a vector containing the cosine for each element of `this`.
  - `sin: () => Vec2` - Returns a vector containing the sine for each element of `this`.
  - `sinCos: () => [Vec2, Vec2]` - Returns a tuple of two vectors containing the sine and cosine for each element of `this`.
  - `recip: () => Vec2` - Returns a vector containing the reciprocal `1.0/n` of each element of `this`.
  - `lerp: (rhs: Vec2, s: number) => Vec2` - Performs a linear interpolation between `this` and `rhs` based on the value `s`, using the form `this.mul(1.0 - s).add(rhs.mul(s))`. When `s` is `0.0`, the result will be equal to `this`. When `s` is `1.0`, the result will be equal to `rhs`. When `s` is outside of the range `[0, 1]`, the result is linearly extrapolated. The result is guaranteed to be `this` at `s == 0.0` and `rhs` at `s == 1.0`, even when the values differ greatly in magnitude, but it is not monotonic in `s` for nearly equal inputs and may not preserve equal inputs exactly. Consider `lerpMonotonic()` instead when interpolating between values that may be equal or nearly equal.
  - `lerpMonotonic: (rhs: Vec2, s: number) => Vec2` - Performs a linear interpolation between `this` and `rhs` based on the value `s`, using the monotonic form `this.add(rhs.sub(this).mul(s))`. When `s` is `0.0`, the result will be equal to `this`. When `s` is `1.0`, the result will be equal to `rhs`. When `s` is outside of the range `[0, 1]`, the result is linearly extrapolated. Prefer this over `lerp()` when interpolating between values that may be equal or nearly equal: the result is monotonic in `s` and equal inputs are preserved exactly, avoiding the rounding jitter that `lerp()` can introduce. The tradeoff is that `rhs.sub(this)` is evaluated first, so this is less accurate than `lerp()` when `this` and `rhs` differ greatly in magnitude, and overflows to infinity when they have opposite signs and large magnitudes.
  - `moveTowards: (rhs: Vec2, d: number) => Vec2` - Moves towards `rhs` based on the value `d`. When `d` is `0.0`, the result will be equal to `this`. When `d` is equal to `this.distance(rhs)`, the result will be equal to `rhs`. Will not go past `rhs`.
  - `midpoint: (rhs: Vec2) => Vec2` - Calculates the midpoint between `this` and `rhs`. The midpoint is the average of, or halfway point between, two vectors. `a.midpoint(b)` should yield the same result as `a.lerp(b, 0.5)` while being slightly cheaper to compute.
  - `absDiffEq: (rhs: Vec2, maxAbsDiff: number) => boolean` - Returns true if the absolute difference of all elements between `this` and `rhs` is less than or equal to `maxAbsDiff`. This can be used to compare if two vectors contain similar elements. It works best when comparing with a known value. The `maxAbsDiff` that should be used used depends on the values being compared against. For more see [comparing floating point numbers](https://randomascii.wordpress.com/2012/02/25/comparing-floating-point-numbers-2012-edition/).
  - `clampLength: (min: number, max: number) => Vec2` - Returns a vector with a length no less than `min` and no more than `max`.
  - `clampLengthMax: (max: number) => Vec2` - Returns a vector with a length no more than `max`.
  - `clampLengthMin: (min: number) => Vec2` - Returns a vector with a length no less than `min`.
  - `mulAdd: (a: Vec2, b: Vec2) => Vec2` - Computes `(this * a) + b` element-wise.
  - `reflect: (normal: Vec2) => Vec2` - Returns the reflection vector for a given incident vector `this` and surface normal `normal`. `normal` must be normalized.
  - `refract: (normal: Vec2, eta: number) => Vec2` - Returns the refraction direction for a given incident vector `this`, surface normal `normal` and ratio of indices of refraction, `eta`. When total internal reflection occurs, a zero vector will be returned. `this` and `normal` must be normalized.
  - `fromAngle: (angle: number) => Vec2` - Creates a 2D vector containing `[Math.cos(angle), Math.sin(angle)]`. This can be used in conjunction with the `rotate()` method, e.g. `Vec2.fromAngle(Math.PI).rotate(Vec2.Y)` will create the vector `[-1, 0]` and rotate `Vec2.Y` around it returning `Vec2.Y.neg()`.
  - `toAngle: () => number` - Returns the angle (in radians) of this vector in the range `[-π, +π]`. The input does not need to be a unit vector however it must be non-zero.
  - `angleTo: (rhs: Vec2) => number` - Returns the angle of rotation (in radians) from `this` to `rhs` in the range `[-π, +π]`. The inputs do not need to be unit vectors however they must be non-zero. The returned angle can be used with `rotateAngle()`, e.g. `this.rotateAngle(this.angleTo(rhs))` will be equal to `rhs`.
  - `perp: () => Vec2` - Returns a vector that is equal to `this` rotated by 90 degrees.
  - `perpDot: (rhs: Vec2) => number` - The perpendicular dot product of `this` and `rhs`. Also known as the wedge product, 2D cross product, and determinant.
  - `rotate: (rhs: Vec2) => Vec2` - Returns `rhs` rotated by the angle of `this`. If `this` is normalized, then this just rotation. This is what you usually want. Otherwise, it will be like a rotation with a multiplication by `this`'s length. This can be used in conjunction with the `fromAngle()` method, e.g. `Vec2.fromAngle(Math.PI).rotate(Vec2.Y)` will create the vector `[-1, 0]` and rotate `Vec2.Y` around it returning `Vec2.Y.neg()`.
  - `rotateAngle: (angle: number) => Vec2` - Rotates `this` by `angle` (in radians), equivalent to `this.rotate(Vec2.fromAngle(angle))`.
  - `rotateTowards: (rhs: Vec2, maxAngle: number) => Vec2` - Rotates towards `rhs` up to `maxAngle` (in radians). When `maxAngle` is `0.0`, the result will be equal to `this`. When `maxAngle` is equal to `Math.abs(this.angleTo(rhs))`, the result will be parallel to `rhs`. If `maxAngle` is negative, rotates towards the exact opposite of `rhs`. Will not go past the target.
  - `div: (rhs: number | Vec2) => Vec2`
  - `mul: (rhs: number | Vec2) => Vec2`
  - `add: (rhs: number | Vec2) => Vec2`
  - `sub: (rhs: number | Vec2) => Vec2`
  - `rem: (rhs: number | Vec2) => Vec2`
  - `neg: () => Vec2`
  - `addAssign: (rhs: number | Vec2) => this`
  - `subAssign: (rhs: number | Vec2) => this`
  - `mulAssign: (rhs: number | Vec2) => this`
  - `divAssign: (rhs: number | Vec2) => this`
  - `remAssign: (rhs: number | Vec2) => this`
  - `eq: (rhs: number | Vec2) => boolean`
  - `ne: (rhs: number | Vec2) => boolean`
  - `approxEq: (rhs: number | Vec2) => boolean`
  - `toString: () => string`
  - `vec2: (x: number, y: number) => Vec2` - Creates a 2-dimensional vector.
